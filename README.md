# Дом Гаргамеля: Онлайн

Клиент (Three.js, 3D от первого лица) + сервер (Node.js, WebSocket) + база данных (SQLite). Без npm-зависимостей.

## Запуск у себя
Нужен Node.js 22.5+.

    node server.js        # http://localhost:3000

Открой адрес, зарегистрируйся (ник + пароль), создай комнату, отправь друзьям код или ссылку.

## Запуск в интернете (игра с разных устройств)
Сервер должен быть доступен по публичному HTTPS-адресу (браузер сам использует wss://).
Подойдёт Render / Railway / Fly.io (Node или Docker) или любой VPS.

1. Залей папку проекта в GitHub.
2. Render: New → Web Service → репозиторий. Runtime: Docker (есть Dockerfile) или Node (Start Command: `node server.js`).
3. ВАЖНО: подключи постоянный диск (Disk, например /data) и задай переменную `DB_PATH=/data/game.db`.
   Без диска аккаунты и монеты стираются при каждом перезапуске.
4. Открой выданный адрес (https://имя.onrender.com) — это и есть игра. Друзья заходят по ссылке-приглашению из лобби.

Бесплатные тарифы «засыпают» без трафика: первое подключение может занять ~30 с, клиент переподключается сам.
VPS: `docker build -t game . && docker run -d -p 3000:3000 -v gamedata:/data game`, HTTPS — через Caddy или nginx.

## Как устроено
- server.js — HTTP + собственный WebSocket (RFC 6455), аккаунты (scrypt + соль), токены сессий, комнаты с 5-символьным кодом, лобби, чат, игровой цикл 20 тиков/с.
- shared.js — геометрия дома и физика (одинаковая на сервере и в клиенте).
- index.html — клиент: вход, меню, лобби, чат, 3D-игра, автопереподключение (возврат в игру по токену).
- game.db (SQLite): users (ник, хэш пароля, монеты, победы, игры, побеги, поимки) и sessions.
- test.js, test2.js — интеграционные тесты сервера (node server.js на порту 3055/3056, затем node test.js).

## Защита от читов
Сервер авторитетный: клиент шлёт только направление движения и взгляд. Позицию, скорость, стамину, ключи, поимку, укрытия, выход и награды считает сервер.
Входные числа проверяются и ограничиваются, лимит 80 сообщений/с (иначе отключение), действия не чаще 4/с, чат 1 сообщение/0,7 с с очисткой символов и выводом через textContent.
Спрятанные гномики не передаются Гаргамелю по сети (только на время «чутья»). Пароли хранятся как scrypt-хэш, перебор ограничен по IP.
Ограничение: направление взгляда клиент присылает сам — от «аимбота» в играх от первого лица полностью не защититься.
